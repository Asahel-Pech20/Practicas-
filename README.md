## Archivos Comprimidos (.ZIP) Incluidos

En este repositorio se encuentran los archivos `.zip` optimizados y listos para descarga y entrega en Teams:

### 1. `Tarea-Aplicaciones-Web-4C-Santiago-Pech.zip` (Entrega Completa)
Contiene la totalidad de los módulos y actividades desarrolladas en la materia:
- **01-Introduccion-al-Desarrollo-Web:**
  - Actividad 1: Conceptos Generales de la Web (con documento `.docx` y código).
  - Actividad 2: Configuración de Entorno y Herramientas (con documento `.docx` y script de verificación).
- **02-Desarrollo-Frontend-Fundamentos:**
  - Actividad 3: Estructura Semántica con HTML5.
  - Actividad 4: Estilos, Flexbox y Grid con CSS3.
  - Actividad 5: Fundamentos y las 11 prácticas completas de JavaScript (Notion).
- **03-Proyecto-Angular-WebNews:**
  - `backend-api`: Servidor RESTful en Node.js + Express con persistencia JSON y autenticación JWT.
  - `webnews-frontend`: Aplicación SPA en Angular Material con inicio de noticias, lector completo en diálogo modal, ruta `/noticia/:id`, panel administrativo, probador interactivo de endpoints (`/tester`) y catálogo de retos de JavaScript (`/retos`).
- **Lanzadores por lotes (.bat):**
  - `PANEL-PORTAL-TESTER-RETOS.bat`: Menú interactivo centralizado.
  - `ABRIR-PORTAL-WEB.bat`: Inicio automático de backend y frontend con apertura en navegador.
  - `EJECUTAR-TODO-EN-ORDEN.bat`: Ejecución secuencial de todas las prácticas.
  - `EJECUTAR-PRACTICAS-JAVASCRIPT.bat`: Ejecución de los retos y simuladores de JavaScript en consola.

### 2. `WebNews-Portal-Angular-Api-RetosJS.zip` (Proyecto WebNews + Retos)
Contiene específicamente el proyecto de portal de noticias y sus módulos integrados:
- Frontend Angular Material (WebNews, Lector de Noticias, Tester API, Retos JS).
- Backend REST API (Node.js/Express).
- Scripts `.bat` para ejecución en un solo clic.

---

## Instrucciones Rápidas de Ejecución

1. Descomprimir el archivo `.zip` deseado en cualquier carpeta de tu equipo.
2. Ejecutar el archivo `ABRIR-PORTAL-WEB.bat` o `PANEL-PORTAL-TESTER-RETOS.bat`.
3. El sistema verificará e instalará las dependencias necesarias e iniciará la aplicación en `http://localhost:4200`.
